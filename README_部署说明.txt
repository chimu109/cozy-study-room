轻松自习室 V2 — 电脑/平板/手机通用版

1. 在 GitHub 新建仓库 cozy-study-room（建议独立于专注森林）。
2. 将本文件夹里的 index.html、sw.js、manifest.webmanifest、icon-192.png、icon-512.png 以及整个 assets 文件夹上传至仓库根目录。注意 assets 中的 8 张 webp 角色图必须完整上传。
3. 在 Settings > Pages 选择 Deploy from a branch / main / (root) 并保存。
4. 访问 https://chimu109.github.io/cozy-study-room/ 即可在电脑、平板和手机打开（前提是部署完成）。
5. 在 Safari 添加到主屏幕可像 App 一样打开。
6. 数据仅存储在各设备浏览器 localStorage 中，三端不会自动同步。可使用界面上的 JSON 导出/导入进行迁移。
7. 所含角色图片摘自用户上传参考图，仅供个人自用。公开 GitHub 仓库内素材可被他人获取，避免二次分发。
